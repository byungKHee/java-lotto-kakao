## 기능 명세서

구입금액 입력
- 가격에 따라서 구매된 로또 개수 측정 기능
  - 1000원 미만은 에러 발생
- 로또 번호 생성
  - 로또 한개당 6개의 랜덤 번호를 생성한다.
    - 각 번호는 1 이상 45 이하여야 한다.
    - 중복이 없어야 한다.

지난 주 당첨 번호를 입력
- ','를 구분자로 해서 6개의 숫자를 입력받는다.
  - 각 번호는 1 이상 45 이하여야 한다.
  - 중복이 없어야 한다.
- 위에 번호와 중복되지 않는 보너스 볼을 입력받는다.

당첨 통계
- 각 로또가 당첨 번호와 몇 개 일치하는지 측정한다.
- 총 수익률을 계산한다.
  - 수익률은 소수점 둘째자리까지 보여준다.
